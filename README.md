# 🛒 বাজার দর | BazarDor

### প্রয়োজনীয় পণ্যের দাম এক নজরে

BazarDor is a Bengali-language grocery price tracking web application that helps users explore essential product prices, compare market prices, and understand daily price changes.

The application provides product categories, price trends, market-wise pricing information, and user authentication.

---

## ✨ Features

### 1. 📊 Product Price Tracking
- View today's prices for essential products.
- Compare today's prices with previous prices.
- See price change percentages and directional indicators.
- Display prices using Bengali numerals.

### 2. 📈 Rising and Falling Prices
- View products whose prices have increased.
- Explore products whose prices have decreased.
- Follow price changes through a scrolling ticker.

### 3. 🗂️ Categories and Price Sorting
- Browse products by category.
- Sort products by default order.
- Sort prices from lowest to highest.
- Sort prices from highest to lowest.

### 4. 🛍️ Product Details and Market Comparison
- View individual product information.
- See minimum, maximum, and average price summaries.
- Compare prices across different markets.
- View product units and price-change information.

### 5. 🔐 Authentication and Profile Management
- Register with name, email, and password.
- Sign in using email and password.
- Use Google OAuth authentication.
- Access the profile menu after signing in.
- Update profile information and sign out.

### 6. 📱 Responsive Design
- Responsive layouts for mobile, tablet, and desktop.
- Horizontally scrollable category navigation.
- Product grids that adapt to screen size.
- Responsive authentication pages.
